# assets/

All raw assets that Godot imports — sprites, UI, fonts, SFX, music.

| Folder | Contents |
|---|---|
| `sprites/heroes/<id>/` | Hero sprite strips: idle, attack, hurt, ult, victory, defeat, portrait |
| `sprites/enemies/<id>/` | Enemy sprite strips (same shape as heroes) |
| `sprites/effects/` | Particle / VFX spritesheets |
| `sprites/backgrounds/` | Battle and hub backgrounds (parallax layers) |
| `ui/panels/` | 9-slice panel artwork |
| `ui/buttons/` | Button states (normal / hover / pressed) |
| `ui/icons/` | Skill icons, item icons, currency icons |
| `fonts/` | Pixel fonts (`.ttf` / `.otf`) |
| `sfx/` | SFX `.wav` / `.ogg` files |
| `music/` | Music loops + stingers (`.ogg`) |

**Always** update [CREDITS.md](CREDITS.md) when importing third-party assets.

See [06 — Art](../docs/06-art.md) for recommended asset packs, palette
(Endesga 64), and animation timing.
